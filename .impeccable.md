## Design Context

### Users
External partner engineers and technical operators integrating Launchpoint data into their own tools. They need to get a key, make a successful first request, understand company versus agency scope, and find endpoint details without hunting.

### Brand Personality
Calm, capable, and trustworthy. The docs should feel as mature as the enterprise product while staying direct and useful for developers.

### Aesthetic Direction
Follow the Launchpoint landing site: bright sky blue, near-black ink, cool tinted neutrals, generous white space, crisp typography, soft rounded framing, and restrained motion. Keep both light and dark themes polished. Avoid generic purple developer-doc styling, neon-on-dark effects, and card-heavy layouts.

### Design Principles
- Make the first successful API call the clearest path on the site.
- Use sky blue as a precise accent; let clean type and space carry the interface.
- Keep technical copy short, literal, and easy to scan.
- Match the landing site through color, logo, type rhythm, and button treatment without turning reference docs into marketing pages.
- Preserve full function, contrast, keyboard access, and readable code at every viewport.
