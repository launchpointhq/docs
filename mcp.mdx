Launchpoint MCP gives AI assistants access to your programs, posts, analytics, creators, payouts, pay terms, contracts, and creator conversations. It can also send creator messages when you ask it to.

Use this hosted Streamable HTTP endpoint:

```text
https://dashboard.launchpointhq.com/api/v1/mcp
```

It uses the same workspace access, creator privacy rules, messaging rules, and rate limit as the REST API. Claude can connect with OAuth, so you do not need to copy an API key into Claude. Other clients can use OAuth when supported or a Launchpoint API key. The only write tool sends creator messages; MCP cannot create invite links or make other changes.

<Warning>
  An MCP connection can read and send creator messages for programs your workspace can manage. Treat it like a person who can speak to creators for your company. Review the recipient and text before asking an assistant to send.
</Warning>

## Connect Claude with OAuth

Add a custom connector in Claude and use this remote MCP URL:

```text
https://dashboard.launchpointhq.com/api/v1/mcp
```

Claude opens Launchpoint in your browser. Sign in, review the requested access, choose **Allow access**, and return to Claude. The connection uses your current Launchpoint workspace and role. A workspace user with a read-only role cannot send creator messages.

In Claude Code, add the server without a header:

```bash
claude mcp add --transport http --scope user launchpoint \
  https://dashboard.launchpointhq.com/api/v1/mcp
```

Then run `/mcp`, select **launchpoint**, and complete authentication in your browser. Check the saved connection with:

```bash
claude mcp get launchpoint
```

## Connect with an API key

Open [Dashboard → Settings → Developer](https://dashboard.launchpointhq.com/campaigns?settings=api), pick your coding tool, then click **Create key & show setup**. The dashboard generates the exact config with a separate key for that connection.

<Warning>
  Launchpoint shows a new key only once. Keep it out of source control, browser code, mobile apps, prompts, and logs. Delete the key from the Developer page if it is exposed.
</Warning>

## Install

Set these values in the examples below:

```bash
export LAUNCHPOINT_API_KEY="lp_pk_..."
```

<Tabs>
  <Tab title="Cursor">
    Add this to `~/.cursor/mcp.json` for all projects, or `.cursor/mcp.json` for one project:

    ```json
    {
      "mcpServers": {
        "launchpoint": {
          "url": "https://dashboard.launchpointhq.com/api/v1/mcp",
          "headers": {
            "Authorization": "Bearer lp_pk_..."
          }
        }
      }
    }
    ```

    Restart Cursor. The Launchpoint tools will appear in **Settings → Tools & MCP**.
  </Tab>

  <Tab title="Claude Code with a key">
    If you prefer a fixed API key instead of OAuth, run:

    ```bash
    claude mcp add --transport http --scope user launchpoint \
      https://dashboard.launchpointhq.com/api/v1/mcp \
      --header "Authorization: Bearer $LAUNCHPOINT_API_KEY"
    ```

    Check the connection:

    ```bash
    claude mcp get launchpoint
    ```
  </Tab>

  <Tab title="Codex">
    Keep the key in `LAUNCHPOINT_API_KEY`, then run:

    ```bash
    codex mcp add launchpoint \
      --url https://dashboard.launchpointhq.com/api/v1/mcp \
      --bearer-token-env-var LAUNCHPOINT_API_KEY
    ```

    Check the connection:

    ```bash
    codex mcp get launchpoint
    ```
  </Tab>

  <Tab title="Other clients">
    Most remote MCP clients accept this standard config:

    ```json
    {
      "mcpServers": {
        "launchpoint": {
          "url": "https://dashboard.launchpointhq.com/api/v1/mcp",
          "headers": {
            "Authorization": "Bearer lp_pk_..."
          }
        }
      }
    }
    ```

    If your client uses a form instead of JSON, choose **Streamable HTTP**, paste the MCP URL, and add `Authorization: Bearer lp_pk_...` as a request header.
  </Tab>
</Tabs>

## Available tools

| Tool | What it does |
| --- | --- |
| `list_programs` | Visible programs, with status and name filters |
| `list_posts` | Posts, current metrics, earnings, creators, and programs |
| `get_post` | One post with metrics, earnings, contract, and bonus details |
| `get_analytics_overview` | Totals, platform breakdowns, top posts, and top creators |
| `list_creators` | Visible creators and their program and social profile summary |
| `list_payouts` | Workspace payout ledger entries |
| `get_payout_stats` | Available money, money owed, deposits, and money paid out |
| `list_pay_structures` | Creator pay terms, CPM or CPC limits, and Canvas payscales |
| `list_contracts` | Visible creator contracts |
| `list_creator_conversations` | Creator conversations for one visible program |
| `list_conversation_messages` | A newest-first page of messages without changing read receipts |
| `send_creator_message` | Sends and stores a real workspace message, then notifies the creator |

Every list tool uses bounded pages. Ask the assistant to keep paging when you need the full matching set.

`send_creator_message` needs a program id, the opaque creator id returned by `list_creators`, and a message. Pass a stable `client_message_id` UUID when retrying so the creator never receives the same message twice.

## Try it

After setup, ask your assistant:

```text
List my active Launchpoint programs, then show the top posts by views.
```

To read messages without sending anything:

```text
List my active programs, then show unread creator messages for the first one. Do not send a reply.
```

To send, name the creator and exact text:

```text
Send Alex this exact message in the Summer Launch program: "Thanks — we received your draft and will review it today."
```

For an agency key, say that you want agency scope:

```text
Using agency scope, compare post performance across my linked brands this month.
```

Agency scope is available only to parent agency keys. Other keys receive a `403`.

## Authentication and limits

OAuth uses the authorization-code flow with S256 PKCE. Launchpoint issues a one-hour access token for this MCP server and a rotating refresh token. Tokens are limited to the `launchpoint:mcp` scope and cannot call Launchpoint REST routes. Disconnecting through a client that supports OAuth revocation invalidates the grant.

API-key clients send the key as a bearer token:

```http
Authorization: Bearer lp_pk_...
```

Each MCP request uses one normal v1 rate-limit slot. The default is 100 requests per minute per connection; approved partner accounts receive 400. A revoked OAuth grant or API key stops working at once.

Launchpoint stores OAuth access tokens, refresh tokens, and authorization codes only as one-way hashes. It does not give Claude your Launchpoint password. See the [Launchpoint Privacy Policy](https://www.launchpointhq.com/privacy) for how Launchpoint handles data. For connector or account support, email [hi@launchpointhq.com](mailto:hi@launchpointhq.com).

## Troubleshooting

<AccordionGroup>
  <Accordion title="The client says unauthorized or returns 401">
    For OAuth, run the client's reconnect or authenticate action and complete the Launchpoint browser flow. For an API key, check that the key starts with `lp_pk_`, is still listed in Dashboard → Settings → Developer, and is sent as `Authorization: Bearer <key>`.
  </Accordion>

  <Accordion title="The server returns 403">
    API access is not enabled for this workspace, or the key requested agency scope without agency access. Email [Launchpoint support](mailto:hi@launchpointhq.com) if the Developer section is missing.
  </Accordion>

  <Accordion title="The tools do not appear">
    Restart the MCP client after changing its config. In Claude Code, run `/mcp` and confirm that launchpoint is authenticated. In Claude Code or Codex, run the matching `mcp get launchpoint` command above and confirm the URL.
  </Accordion>

  <Accordion title="Codex works in one terminal but not the next">
    `codex` reads the bearer token from `LAUNCHPOINT_API_KEY`. Save that variable in your shell or secret manager before starting Codex again.
  </Accordion>

  <Accordion title="The server returns 429">
    The key reached its per-minute limit. Wait for the reset time before retrying, or use fewer pages per request.
  </Accordion>
</AccordionGroup>
