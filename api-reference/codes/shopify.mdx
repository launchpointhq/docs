## Connecting to Shopify

Make sure you connect your Shopify store to your Launchpoint account in the [Shopify settings](https://buyer.launchpoint.nyc/settings#shopify)

## Creating codes

First, create a master discount code in your Shopify dashboard. Then, add a new Shopify Group in the [codes tab](https://buyer.launchpoint.nyc/codes). Enter the discount code that you just generated in Shopify. Add the commission you want to give the creator.

<Info>
  Launchpoint will make a copy of your master discount code for each creator who signs up, and track the sales for each
</Info>

## Updating

You don't need to do anything. Launchpoint will keep track of usage and pay creators accordingly.
