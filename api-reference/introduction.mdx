The Launchpoint Public API is a read-focused REST API for brands and agencies. It exposes the same verified program, post, performance, creator, contract, and payout data used inside Launchpoint.

<Card title="Make your first request" icon="zap" href="/quickstart" horizontal>
  Create a key and fetch your programs in a few minutes.
</Card>

## Use the production base URL

All requests use:

```text
https://dashboard.launchpointhq.com/api/v1
```

## Authenticate every request

Create an API key in [Dashboard → Settings → API](https://dashboard.launchpointhq.com/settings#api), then send it in the `x-api-key` header:

```javascript
const headers = {
  "x-api-key": "lp_pk_...",
};
await fetch("https://dashboard.launchpointhq.com/api/v1/programs", {
  headers,
});
```

Do not expose API keys in browser code or commit them to source control.

<Warning>
  API access must be enabled for your company. If the API section is hidden, contact [Launchpoint support](mailto:hi@launchpointhq.com).
</Warning>

## Choose company or agency scope

Routes that support `scope` use `scope=company` by default. This returns only the API key company's data.

A parent agency can pass `scope=agency` to include its own data and data from linked brands. Other keys receive `403` for this scope.

## Stay within the rate limit

The standard limit is 100 requests per minute per API key. Approved partner accounts receive 400 requests per minute. This v1 budget is counted separately from the dated public API. Every response includes the current limit, remaining requests, and reset time in `X-RateLimit-*` headers.

Requests over the limit return `429`.

## Handle errors by status

Errors use this shape:

```json
{ "error": "Invalid request" }
```

Some errors also include a `code`. A company without API access or a ready payment method receives `402` with `Active subscription required`.

| Status | Meaning |
| --- | --- |
| `400` | The request is missing or has an invalid value. |
| `401` | The API key is missing or invalid. |
| `402` | API access or the company's payment setup is not ready. |
| `403` | The key cannot access the requested company or agency scope. |
| `404` | The requested record was not found. |
| `429` | The API key has reached its per-minute limit. |
| `500` | Launchpoint could not complete the request. |

## Read timestamps and pages

Timestamps are Unix timestamps in milliseconds unless a field says otherwise.

Most list endpoints accept `page` and `limit` and return `data`, `page`, and `total`. Some also return `totalPages`.
