## Base URL

All requests use:

```text
https://dashboard.launchpointhq.com/api/v1
```

## Authentication

Create an API key in [Dashboard → Settings → API](https://dashboard.launchpointhq.com/settings#api). Send it in the `x-api-key` header:

```javascript
const headers = {
  "x-api-key": "lp_pk_...",
};
await fetch("https://dashboard.launchpointhq.com/api/v1/programs", {
  headers,
});
```

Do not expose API keys in browser code or commit them to source control.

## Company and agency data

Routes that support `scope` use `scope=company` by default. This returns only the API key company's data.

A parent agency can pass `scope=agency` to include its own data and data from linked brands. Other keys receive `403` for this scope.

## Rate limits

The standard limit is 100 requests per minute per API key. Approved partner accounts receive 400 requests per minute. This v1 budget is counted separately from the dated public API. Every response includes the current limit, remaining requests, and reset time in `X-RateLimit-*` headers.

## Errors

Errors use this shape:

```json
{ "error": "Invalid request" }
```

Some errors also include a `code`. A company without API access or a ready payment method receives `402` with `Active subscription required`.
